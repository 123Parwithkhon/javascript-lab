# JavaScript Lab

Интерактивная платформа для изучения JavaScript в браузере: без установки программ и без регистрации.

Сейчас готов первый шаг: главная страница, песочница и безопасный запуск кода. Уроков и заданий пока нет.

## Что нужно

- Node.js 22 или новее (проверено на 24.11.1)
- npm (проверено на 11.6.2)

## Запуск

```powershell
npm install
npm run dev
```

Откройте адрес из терминала, обычно http://localhost:5173.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | запускает проект для разработки |
| `npm run typecheck` | проверяет типы TypeScript |
| `npm run build` | проверяет типы и собирает проект в папку `dist` |
| `npm run preview` | показывает собранную версию |
| `npm run test:edge` | запускает тесты в установленном Microsoft Edge, ничего не скачивая |
| `npm test` | запускает тесты в Chromium, Firefox и WebKit |

Перед первым запуском `npm test` один раз скачайте браузеры:

```powershell
npx playwright install chromium firefox webkit
```

## Структура

| Папка | За что отвечает |
|---|---|
| `src/sandbox` | запуск кода ученика и ограничения |
| `src/components` | редактор, консоль, общий каркас страниц |
| `src/pages` | страницы сайта |
| `src/i18n` | все тексты интерфейса |
| `tests` | тесты в настоящих браузерах |
